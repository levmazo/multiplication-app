# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Что это за проект

Игра-тренажёр таблицы умножения (0–12), которую делает ребёнок Лёва вместе с Claude. Цель проекта двойная: Лёва учит таблицу умножения и одновременно учится делать продукт. Обычный веб без сборки: три файла в корне, открывается двойным кликом по `index.html`.

## Как работать с Лёвой (важно)

- Отвечать **по-русски**. Лёва часто пользуется голосовым вводом — в сообщениях бывают ошибки распознавания; при непонятном тексте переспрашивать, а не угадывать.
- **Сначала обсудить, потом код.** Проговорить, что и как будешь делать, и начинать реализацию только после явного «да»/«делай» — даже если Лёва забыл включить Plan Mode.
- **Коммит и пуш — только с подтверждения.** Напомнить можно, выполнять — после явного «закоммить».
- При обсуждении фич честно оценивать приоритет относительно главной цели (выучить таблицу умножения): необходимое / полезное / украшение. Выбор остаётся за Лёвой.
- Экономика игры — предмет гордости Лёвы: награды не должны делать выгодным «фарм» лёгких примеров (×0, ×1...). Проверять новые фичи на такие лазейки и предупреждать о них.
- Монетизация: сейчас только игровые «евро», но архитектура должна оставлять возможность позже подключить реальную оплату (все начисления идут через `addCoins()`).

## Команды

- Запуск: `open index.html` (после правок напомнить Лёве обновить вкладку, Cmd+Shift+R).
- Проверка синтаксиса: `node --check game.js`. Тестов и линтера нет.
- Деплой: GitHub Pages собирается автоматически из `main` → https://levmazo.github.io/multiplication-app/ (репозиторий `levmazo/multiplication-app`). Пуш в main = публикация; живая версия обновляется ~1 мин, дальше кэш браузера.
- Сообщения коммитов — по-русски, кратко describing суть.

## Архитектура

Три файла: `index.html` (все экраны как секции, показ/скрытие через класс `.hidden`), `style.css`, `game.js` (вся логика, ~1000 строк, секции помечены `// === ... ===`).

### Модель данных (game.js)
- `facts` — все 169 примеров `{a, b, streak, mastered, wrong, mt}`; `3×5` и `5×3` — РАЗНЫЕ примеры, «близнец» ищется через `twin(f)`. `wrong` — счётчик ошибок за всё время, `mt` — максимальное время ответа (для подбора диктанта).
- Пример «выучен» = `NEED_STREAK` (2) правильных ответа ПОДРЯД; ошибка сбрасывает streak в 0.
- Персистентность — localStorage: `mult_progress` (прогресс, монеты, питомцы, настройки — всё через `saveState()`/`loadState()`), `mult_lang` (язык), `mult_fix_306` (одноразовые миграции-починки — этот паттерн используется, когда надо исправить сохранённые данные пользователя).

### Режимы игры
Единый обработчик ввода ветвится по `mode`: `'session'` (обучение) или `'dictTest'` (диктант).
- **Сеанс** (`startSession`) — объект `session` с флагами: `temp` (временный счётчик, не трогает глобальный прогресс), `progress` (двигать глобальный `mastered`), `kind`: `'random'` (случайный набор — 2 случайные таблицы), `'custom'` (свой выбор), `'dictLearn'` (доучивание ошибок диктанта).
- **Диктант** — по выученному; длина задаётся числом (минимум 15, максимум — сколько выучено); `selectDictExamples()` подбирает примеры по приоритету: чаще всего ошибался → медленно решал (`mt > SLOW_MS`) → сложные. Ошибка в диктанте добавляет пример И его близнеца в доучивание (`dictLearn`, temp), после — повторный раунд только по ним, до чистого прохода.

### Экономика
- Награда за пример — `factValue(a,b)` = min из «сложности» множителей: лёгкие (0,1,2,5,10,11)=10, средние (3,4)=70, сложные (6,7,8,9,12)=300. Пример с хотя бы одним лёгким множителем — лёгкий. Это защита от фарма — не ломать.
- Питомцы (`REGULAR_PETS`/`LEGENDARY_PETS`) — коллекция; из купленных назначаются роли: `bonusPet` (множитель к награде, % по прайсу питомца) и `hintPet` (подсказки — у каждого питомца свой способ/`hint`: рамка, соседний, сложение и т.д., тексты в `methodStr`). Праздники (`CELEBS`) — косметика на экран победы.

### Локализация
Все строки UI — через `STR` (ru/nl/en) и `t(key, params)`; статичные тексты в HTML — атрибут `data-i18n`, применяет `applyLang()`. **Любой новый текст добавлять во все три языка** — непереведённый ключ отобразится как есть (такой баг уже был). Кнопка языка всегда «⚙ Language»; названия языков в списке не переводятся.
